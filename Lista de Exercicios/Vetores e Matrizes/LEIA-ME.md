# Exercícios de Matrizes e Vetores em Java

Soluções das 10 atividades do material **LOPAL — Vetores e Matrizes em Java**.

## Exercícios resolvidos

1. Soma de todos os elementos de um vetor.
2. Maior elemento de um vetor.
3. Contagem de números pares em um vetor.
4. Exibição de um vetor em ordem inversa.
5. Média dos elementos de um vetor de notas.
6. Soma de todos os elementos de uma matriz 3x3.
7. Maior valor de uma matriz.
8. Soma dos elementos de cada linha de uma matriz.
9. Contagem de números pares em uma matriz.
10. Busca do valor 8 em uma matriz.

As matrizes dos exercícios 6 a 10 foram declaradas diretamente nos respectivos arquivos para tornar os exemplos executáveis sem entrada externa.

## Como compilar e executar

Dentro desta pasta, execute:

```bash
javac Questao*.java
java Questao01
```

Para executar outra questão, troque `Questao01` pelo nome correspondente.
